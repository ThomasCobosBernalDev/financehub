Write the steps once. Let the computer repeat them.

The story so far Your tune-up spreadsheet (Lesson 17.1) works. Now you want to put $200 a month, or $2,400 a year, from tune-ups into an index fund (Lesson 5.3). If it earns 7% a year, how much will you have in 30 years? And what if it earns 4%, or 10%? In a spreadsheet, that's 30 rows for every guess. In Python, it's four lines, and the computer repeats them for you. That's why banks, funds and fintech companies hire people who can code.

What

Python is a programming language: you write steps in plain-looking text, and the computer runs them, in order.

Why

It repeats work in a blink, handles millions of rows that would break a spreadsheet, and runs the same report again tomorrow with one click.

How

Store numbers in variables, keep many in a list, repeat steps with a loop, and wrap steps you reuse in a function.

Who

Quant analysts test trading ideas in it. Risk teams run thousands of scenarios. Data analysts at banks clean and study huge data sets.

What you're looking at: a short Python program. It starts with $0, then 30 times it grows the balance by 7% and adds this year's $2,400. The last line prints the result: about $226,706. The green line at the bottom is the output.

Code is a recipe the computer follows.

Python runs your lines from top to bottom. A variable is a name that holds a value: the = sign means "store this", not "is equal to". print() shows a result on the screen.

price = 40 tune_ups = 25 revenue = price * tune_ups print(revenue)1000

Lists: many numbers under one name

A list keeps many values in square brackets. sum() adds them up, and len() counts them. Python divides with the slash key: sum(months) / len(months) means sum(months)len(months), the average.

months = [20, 25, 30] print(sum(months)) print(len(months)) print(sum(months) / len(months))75 3 25.0

len(months)

The average
753 = 25.0. Python shows .0 after a division.

Loops: repeat the steps

A for loop repeats the lines indented under it. range(3) gives the numbers 0, 1 and 2, so the loop runs 3 times. The spaces at the start of a line matter: indented lines are inside the loop, and the first line that isn't indented runs after it ends. Each time, balance = balance * 1.10 takes the old balance, grows it 10%, and stores the new one under the same name.

balance = 1000 for year in range(3): balance = balance * 1.10 print(round(balance))1331
In this example
Each pass
$1,000 → $1,100 → $1,210 → $1,331, the same compound growth as Lesson 10.1.
round()
Rounds to a whole number, so you don't see 1331.0000000000005.

Functions and decisions

A function wraps steps you reuse: def names it, and return sends back the answer. An if lets code decide: the indented line under if runs only when the test is true; otherwise, the line under else runs.

def profit(tune_ups): return tune_ups * 30 - 300 print(profit(20)) npv = 1372 if npv > 0: print("Build it") else: print("Skip it")300 Build it

Worked example: test three rates at once

You want the 30-year balance at 4%, 7% and 10% without running the code three times. Here are the facts:

  • You save: $2,400 a year for 30 years.
  • The rates: 4%, 7% and 10%, kept in a list: [0.04, 0.07, 0.10].
  • The tool: a loop inside a loop.
for rate in [0.04, 0.07, 0.10]: balance = 0 for year in range(30): balance = balance * (1 + rate) + 2400 print(rate, round(balance))0.04 134604 0.07 226706 0.1 394786
  1. Outer loop. It runs 3 times, once for each rate.
  2. Reset. balance = 0 sits inside the outer loop, so every rate starts fresh.
  3. Inner loop. 30 passes, the same savings rule as before.
  4. The answer. $134,604, $226,706 and $394,786. Going from 4% to 10% nearly triples your money, which is why low fees and a good mix of investments matter so much.

A sunflower runs one line of code.

Look closely at a sunflower's center and you'll see spirals. The plant follows one simple rule: each new seed grows about 137.5° around from the last one, a little farther out. Repeated hundreds of times, that one rule packs the seeds with almost no gaps.

What you're looking at: a drawing made with the sunflower's own rule. Each of the 239 seeds was placed 137.5° around from the one before it, a little farther from the center.

Why this sticks. The sunflower doesn't plan each seed; it repeats one step. Code works the same way: you write one careful rule, and a loop applies it 30 times, or 30 million.
